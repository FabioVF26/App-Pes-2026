# P&S Gestionale v0.3

Gestionale Android per clienti e servizi HACCP, Sicurezza sul lavoro e GDPR di Progetti e Soluzioni.

## Novità v0.3
- logo launcher ridimensionato con area di sicurezza più ampia;
- schermata iniziale bianca con logo completo Progetti e Soluzioni;
- ricerca clienti;
- modifica anagrafica e servizi del cliente;
- archiviazione cliente senza cancellazione fisica dei dati;
- gestione di più sedi operative per cliente;
- funzione Naviga disponibile per ogni sede registrata;
- struttura sopralluoghi già predisposta per i prossimi moduli HACCP, Sicurezza e GDPR.

## Build GitHub Actions
Il workflow `.github/workflows/build-apk.yml` usa JDK 17, Android SDK 37.0 e Gradle 9.5.0.
L'APK debug viene pubblicato come artifact `PS-Gestionale-v0.3-debug`.
